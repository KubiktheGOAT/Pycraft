PyCraft

An open-source voxel sandbox built in Python.

PyCraft is a Minecraft-inspired voxel game written in Python. The project focuses on multiplayer gameplay, PvP, customization, and extensibility through a built-in modding API.

Features

* Block-based 3D world
* Procedural world generation
* Multiplayer
* Player-versus-player combat
* Weapons, tools, and armor
* Upgrade system
* Inventory and crafting
* Resource pack support
* Built-in mod loader
* Public modding API
* Custom user interface
* Open-source development
* No monetization

Gameplay

PyCraft is designed around the core concept of a block-based sandbox game while providing its own implementation, systems, interface, and content.

Players will be able to explore, gather resources, build structures, craft equipment, and interact with other players in multiplayer worlds.

Combat

PvP is a core part of PyCraft.

The initial weapon system is intentionally straightforward and includes traditional weapons such as:

* Swords
* Axes
* Bows
* Crossbows
* Tridents
* Maces

Weapons, tools, and armor can receive upgrades that improve their properties.

Multiplayer

PyCraft is designed with multiplayer in mind.

Players will be able to connect to dedicated PyCraft servers and:

* Explore worlds together
* Build and modify environments
* Fight other players
* Communicate through in-game chat
* Use custom content
* Participate in community-created game modes

Modding

PyCraft includes a built-in mod loader and public API designed to allow developers to extend the game without modifying its core source code.

Mods will be able to add:

* Blocks
* Items
* Weapons
* Entities
* Commands
* Events
* User interface elements
* Gameplay mechanics

The API will be designed to remain simple and accessible for developers familiar with Python.

Resource Packs

PyCraft supports custom resource packs for modifying the game’s visual and audio assets.

Resource packs may contain:

* Block textures
* Item textures
* Entity textures
* User interface assets
* Sounds
* Music

PyCraft will include an original default resource pack.

Development will begin with the core game systems before expanding into multiplayer, PvP, modding, and customization.

PyCraft is intended to remain completely open source and non-monetized.

The project’s original source code and assets will be distributed under an open-source license.

Third-party content remains subject to its respective licenses.
