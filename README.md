PyCraft

An open-source voxel sandbox built in Python.

PyCraft is a Minecraft-inspired voxel game focused on multiplayer, PvP, customization, and modding.

Features

* 3D block-based worlds
* Multiplayer
* PvP combat
* Weapons, tools, and upgrades
* Inventory and crafting
* Resource packs
* Built-in mod loader
* Public Python modding API
* Custom UI
* Fully open source
* No monetization

Development

PyCraft is currently in development.

Roadmap

* 3D renderer
* Player movement
* Blocks
* World generation
* Inventory and crafting
* Combat
* Multiplayer
* Mod loader and API
* Resource packs

License

PyCraft is intended to remain free, open source, and non-monetized. Third-party content remains subject to its respective licenses.
